## 三、三大块操作要点

### 部署
- 镜像 `calciumion/new-api:latest`，端口 3000，数据目录 `/data`，首访引导设管理员。
- 生产推荐 PostgreSQL+Redis；MySQL 兼容；SQLite 仅测试。
- 必要环境变量：`SESSION_SECRET`(多机必填，不可设 random_string)、`CRYPTO_SECRET`(用 Redis 时必填，默认跟随 SESSION_SECRET)。
- docker-compose：`git clone` → `docker compose up -d`（自带 yml 已配 PG+Redis）。
- 集群主从：全节点共享 PG；SESSION_SECRET 全相同；共享 Redis 则 CRYPTO_SECRET 也相同；从节点 `NODE_TYPE=slave`；Nginx 按权重负载均衡。

### 用户
- 注册：账号密码 + GitHub/Discord/LinuxDO/OIDC/Telegram OAuth；注册需邮箱验证码。
- 令牌 `/console/token`：高级配置含 过期时间/剩余配额/无限配额/模型限制/IP白名单/分组；**Key 仅创建时显示一次**。
- 使用 API：平台地址替换 OpenAI base_url，令牌作 api_key；内置操练场 `/console/playground`。
- 充值：兑换码/EPay/Stripe/Creem/Waffo；邀请返利。

### 管理员
- **渠道** `/console/channel`：每条=一个服务商 Key；高级配置含 Base URL/优先级(越高越优先)/权重(同优先级加权随机)/**模型映射**(JSON)/**参数覆盖**(JSON)/自动禁用；**多 Key 模式**(轮询/加权随机，单 Key 失败跳过)；可单/批量测试。
- 用户管理 `/console/user`：改角色/分组/配额/启停。
- 模型管理 `/console/models`：元数据+定价，同步上游(预览新增/变更/删除)。
- 分组：隔离渠道访问权限与计费倍率；令牌分组设 `auto` 自动选可用分组(跨分组容灾)。
- **系统设置(Root)** `/console/setting`：通用/计费倍率/注册安全/OAuth/邮件(SMTP)/Worker/支付/限流/聊天/绘图/数据看板/模型/运营/其他。
- 性能监控(Root)：实时指标 + 维护操作(清磁盘缓存/重置统计/强制GC/清日志)。

## 六、★参数覆盖系统（改 max_tokens 的另一强大落点！第6章核心）
**模型映射**（渠道高级配置 JSON）：用户请求模型名 → 上游实际模型名。
**参数覆盖**（渠道高级配置 JSON，两种模式）：
- 简单模式：`{"temperature":0.8,"max_tokens":2000,"model":"gpt-4"}` 直接合并到原始请求。
- 高级模式 `operations` 数组，15 种 `mode`：`set/delete/move/append/prepend/copy/trim_prefix/trim_suffix/ensure_prefix/ensure_suffix/trim_space/to_lower/to_upper/replace/regex_replace`。
- 条件 `conditions`(匹配 `full/prefix/suffix/contains/gt/gte/lt/lte` + `invert` + `pass_missing_key`) + 逻辑 `AND/OR`。
- 路径语法：`temperature`、`messages.0.content`(首条)、`messages.-1.content`(末条)、`metadata.user.name`。
- 内置变量：`model`/`upstream_model`(重定向后)、`original_model`(重定向前)。
- `keep_origin`：set 时已有值则跳过。
- 官方限定原话：**"参数覆盖功能只能用于兼容合法上游接口格式、企业网络兼容和请求规范化。"**

**请求透传**：系统设置-模型相关设置中可配"请求透传、连接保活和针对特定模型的设置"——⚠️ 官方正文仅截图无文字 → 已从源码补齐（见 03/05：全局 PassThroughRequestEnabled / 渠道 PassThroughBodyEnabled / 字段透传控制）。

## 七、官方表述（可直接引用）
1. 定位："New API 是面向合法授权场景的 AI API 网关与用量管理系统……默认面向自用、团队内部和企业私有化部署。"
2. 配额：**1 美元 = 500,000 配额点数**；按量 `配额=(输入token+输出token×补全倍率)×模型倍率×分组倍率`；按次 `配额=固定价×分组倍率×500000`。
3. 倍率参考：gpt-4o 1.25/补全4；gpt-3.5-turbo 0.25/1.33；gpt-4o-mini 0.075/4；o1 7.5/4。未设倍率：自用模式默认 37.5，计费模式报错。
4. 限流默认：API 180/180s、Web 60/180s、关键操作 20/1200s；分组限流 `{"default":[200,100],"vip":[0,1000]}`(0=不限)。
5. 中继超时警示："设置 RELAY_TIMEOUT 时请谨慎……上游已计费但本地超时未计费，可能亏损，建议不设置。" 流式 STREAMING_TIMEOUT 默认 300s。
6. 客户端接入三要素：API 地址、API Key(令牌)、模型名称。"大多数支持 OpenAI API 的应用都可以通过填写自定义 API 地址的方式接入。"
7. 鉴权：Session 或 Access Token(`Authorization: Bearer {token}`，个人设置-安全设置-系统访问令牌)；部分接口需 `New-Api-User: {user_id}` 头。
