## ⚠️ 关键发现（影响最大 / 与旧教程冲突）

### 1. 首次部署已不再用默认 root/123456，改为「初始化向导」
- `model/main.go:57` 的 `createRootAccountIfNeed` 是**死代码**（无调用方）。
- 现行流程：启动时 `CheckSetup()` 查 `setups` 表 → 前端检测 `setup=false` 展示初始化向导 → `POST /api/setup`（`controller/setup.go:46`）创建管理员。
- 约束：用户名 ≤ 12 字符，密码 ≥ 8 字符。
- **写说明书铁律**：面向"小白从 0 到 1"的部署章节，必须以初始化向导为准，不要沿用 one-api / 早期 new-api 的 root/123456 说法。

### 2. 数据库三库切换（按 `SQL_DSN` 前缀判别）
- `model/main.go:127-179` `chooseDB`：
  - `postgresql://` → PostgreSQL
  - `local` 或空 → SQLite（默认）
  - 其余 → MySQL（自动补 `parseTime`）
- MySQL 启动会校验中文字符集，不达标直接 panic。
- `LOG_SQL_DSN` 可独立配置（如 ClickHouse，仅限日志库）+ TTL 自动清理。

### 3. Redis 可选
- `REDIS_CONN_STRING` 为空 → `RedisEnabled=false`，程序照常跑（token 缓存 / 限流回退 DB / 内存）。
- 单机可不配；多节点 / 高并发必备。
- 开启 Redis 会强制 `MemoryCacheEnabled=true`。

### 4. 环境变量入口
- 主要入口 `common/init.go:32-227`，已整理为 8 大类大表：数据库 / 缓存 / 服务 / 安全 / 限流 / 转发超时 / 特性 / 监控。每项带变量名、默认值、作用、file:line。
- > 待补充：写章节时把这张大表逐项补全（从 `common/init.go` 与 `common/constants.go` 精读）。

### 5. 配置热更新
- `SyncOptions`（`model/option.go:199`）周期性从 DB 重载 → 后台改设置无需重启；环境变量类配置需重启。

### 6. 安全三件套（生产必须）
- 改默认密码
- `SESSION_SECRET`（多机固定一致）
- `CRYPTO_SECRET`（敏感字段加密；**改密会导致历史数据不可读，必须备份**）
- `SESSION_COOKIE_SECURE` + `SESSION_COOKIE_TRUSTED_URL`（HTTPS 场景）
- `TRUSTED_PROXIES`（反代场景）

### 7. 前端嵌入
- `//go:embed web/dist`（`main.go:41`）把前端编进二进制。
- 构建链：`bun build` → `web/dist`。
- 分离部署用 `FRONTEND_BASE_URL`（主节点忽略）。

### 8. master / slave（多节点）
- `NODE_TYPE=slave` → 跳过迁移和定时任务。
- `NODE_NAME` 用于审计。

### 9. 升级
- 换镜像重启，主节点自动 `AutoMigrate`（跨版本一般无需手动 SQL）。
- **务必先备份 DB + `/data` + `CRYPTO_SECRET`**。
- 多节点：先 slave 后 master。
